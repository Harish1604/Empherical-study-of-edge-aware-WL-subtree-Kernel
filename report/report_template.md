## Abstract
This project implements the Weisfeiler–Lehman (WL) subtree kernel from scratch and evaluates a bond-aware extension for molecular graph classification. The MUTAG benchmark is used to compare standard WL refinement against a variant that incorporates edge labels into node neighbourhood signatures. Experiments use a precomputed-kernel support vector machine and repeated stratified 10-fold cross-validation. The final claims are based on the metrics generated by the accompanying experiment script.

## 1. Introduction
Graph kernels compare graphs through structural patterns and allow standard kernel classifiers, such as support vector machines, to operate on graph-structured inputs. Shervashidze et al. (2011) introduced an efficient WL graph-kernel framework based on iterative node-label refinement. This project studies whether explicitly including chemical bond labels in the refinement step affects classification performance on molecular graphs.

## 2. Dataset
MUTAG is a benchmark of 188 molecular graphs for classifying mutagenic versus non-mutagenic compounds. Nodes represent atoms and carry discrete labels; edges represent chemical bonds and carry discrete bond labels. The dataset is small enough for transparent, reproducible experiments but also means that performance estimates have uncertainty.

## 3. Methodology
### 3.1 Standard WL subtree kernel
Each node begins with its atom label. At iteration `h`, its signature consists of its current label and the sorted multiset of neighbouring node labels. Identical signatures are assigned the same compressed label across all graphs. A graph is represented by counts of labels at every iteration from zero to a chosen maximum height. The kernel between two graphs is the dot product of their feature vectors; vectors are L2-normalized before forming the kernel matrix.

### 3.2 Proposed edge-aware modification
The modified signature contains the current node label and a sorted multiset of `(bond label, neighbour label)` pairs. This allows the refinement to distinguish neighbourhoods with the same atom-label pattern but different bond types. The experiment also tests depth-decayed feature weights, `weight(h) = 0.7^h`, to reduce the influence of higher-order neighbourhoods.

### 3.3 Classifier and evaluation
An SVM with a precomputed kernel and `C=1.0` is evaluated with repeated stratified 10-fold cross-validation (10 repeats, fixed seed 42). Report accuracy, balanced accuracy, macro-F1, ROC-AUC and runtime. All methods use the same protocol. The script writes the measured results to `results/metrics.csv` and creates `results/results_report.md` with the numerical comparison.

## 5. Discussion
The edge-aware variant adds bond information to the neighbourhood refinement and is therefore more chemically expressive than a node-label-only signature. However, a more expressive representation does not guarantee higher predictive performance on a small dataset. The impact depends on the dataset, classifier, iteration depth and evaluation split. Repeated cross-validation reduces dependence on one split but does not eliminate uncertainty.
